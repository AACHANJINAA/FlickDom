How To Play

게임 방법: 목표 · 조작 · 종료 조건

목표

  • 각 플레이어는 3개의 플릭 디스크를 사용한다.
  • 디스크를 보드 위에 배치해 카드가 요구하는 패턴을 완성한다.
  • 카드는 난이도에 따라 Easy 1점, Normal 2점, Hard 3점을 준다.

조작

  • 라운드 시작 시 자신의 디스크 3개를 좌클릭해 사용할 순서를 정한다.
  • 마우스 또는 터치 드래그로 방향과 힘을 잡고 놓으면 디스크가 발사된다.
  • 발사된 디스크는 다른 디스크나 벽에 닿아야 배치 후보가 된다.

종료 조건

  • 매치는 3개의 스테이지 카드 흐름으로 진행된다.
  • 점수 획득 직후 10점에 먼저 도달한 플레이어가 승리한다.
  • 승리 시 중앙에 P1 WIN 또는 P2 WIN 화면이 표시된다.
핵심 재미: 물리 발사로 위치를 만들고, 카드 패턴을 읽어 다음 턴의 배치를 계획하는 전략형 1대1 대결.

Multiplayer Setup

멀티플레이 실행 방법

STEP 01메인 화면에서
MULTIPLAYER 버튼을눌러 방 생성 및 참가 화면으로 이동한다.
STEP 02호스트가 Create Room을 눌러 방을 만들고 Join Code를 생성한다.
STEP 03호스트는 Copy 버튼 또는 메신저로 Join Code를 참가자에게 전달한다.
STEP 04참가자는 전달받은 코드를 입력하고 Join Room을 눌러 접속한다.
STEP 05Players가 2 / 2가 되면 호스트가 Start Game을 눌러 시작한다.
시작 전 준비호스트와 참가자 역할을 정하고, 두 플레이어 모두 게임 실행 및 네트워크 연결 상태를 확인한다.
중요참가자는 새 방을 만들지 말고 호스트가 전달한 Join Code를 입력해야 같은 방에 들어갈 수 있다.
상태 표시방 생성 전에는 Status가 Offline일 수 있고, 생성 후 호스트는 Host, 참가자는 Client로 표시될 수 있다.
코드 전달초대코드는 매번 달라질 수 있으므로 화면에 표시된 최신 Join Code를 전달한다.

Troubleshooting & Summary

문제 해결과 구현 요약

접속 문제 확인

  • 코드 입력 후 접속이 안 되면 대소문자와 앞뒤 공백을 확인한다.
  • Players가 2 / 2로 바뀌지 않으면 Join Room 클릭 여부와 양쪽 네트워크 상태를 확인한다.
  • Start Game은 호스트 전용 버튼이므로 참가자 접속 완료 후 호스트가 시작한다.

핵심 구현

  • 보드, 디스크, 카드, 점수, 승리 흐름을 갖춘 물리 기반 실제 게임으로 구성했다.
  • Host-Client 기반 2인 멀티플레이, 로비, 역할 배정, 보드·카드·점수 동기화를 구현했다.
  • 카드 획득 애니메이션, 카드 공개 연출, 효과음과 BGM을 추가했다.

게임 흐름

  • 메인 메뉴에서 멀티플레이 방을 생성하거나 초대코드로 참가한다.
  • 각 턴마다 디스크를 선택하고 발사해 보드 위 점령 위치를 만든다.
  • 카드 패턴이 완성되면 점수를 획득하고 10점 도달 시 승리한다.

릴리스 형태

  • Unity Editor 테스트와 WebGL 브라우저 실행을 지원한다.
  • WebGL 빌드는 정적 호스팅에 업로드해 공유 가능한 URL로 배포한다.
  • 발표 자료에는 웹 링크, 테스트 링크, 플레이 영상 링크를 기입한다.
