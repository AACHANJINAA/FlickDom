Resource 제작 1

Blender · Substance MCP 기반 리소스 제작

모델 제작

  • Blender MCP를 연결해 보드, 디스크, 소품 등 게임 리소스 제작 과정을 보조했다.
  • AI에게 모델링 방향, 비율, 배치 목적을 지시하고 결과를 Unity 씬 구성에 맞게 정리했다.
  • 반복 수정이 필요한 형태와 배치 요소는 대화형 피드백으로 빠르게 조정했다.
  • 보드, 셀 타일, 시작 트레이, 발사대, 디스크가 플레이 화면에서 읽히도록 크기와 배치를 맞췄다.
  • 제작 리소스는 Unity 프리팹과 씬에 배치할 수 있게 이름, 위치, 축 방향을 정리했다.

머티리얼 제작

  • Substance MCP를 연결해 에셋별 머티리얼 제작과 적용 방향을 보조했다.
  • 보드, 디스크, 셀 타일, 트레이 등 게임 오브젝트의 UV 스케일과 타일링을 수정했다.
  • Assets/04_Arts/Materials의 머티리얼과 Source/Substance preset을 기준으로 결과물을 정리했다.
  • UV가 어긋나는 오브젝트는 Triplanar 셰이더와 머티리얼 값 조정으로 표면 표현을 보정했다.
  • Unity에서 바로 적용할 수 있도록 머티리얼 이름, 색상 구분, 렌더링 설정 흐름을 맞췄다.

Resource 제작 2

VARCO AI 기반 사운드와 BGM 제작

효과음 제작

  • VARCO AI를 활용해 버튼 클릭, 점수 획득, 실패, 승리 등 게임 피드백 효과음을 제작했다.
  • 플레이어가 행동 결과를 즉시 인지할 수 있도록 상황별로 다른 사운드를 배치했다.
  • 필요한 경우 무음 구간을 줄이고 Unity 오디오 리소스로 적용했다.
  • 디스크 충돌, 레일 충돌, 말 이동, 카드 획득 등 반복 행동에 맞는 짧은 효과음을 분리했다.
  • 버튼과 메뉴 조작음은 UI 흐름을 방해하지 않도록 짧고 명확한 톤으로 구성했다.

BGM 제작

  • 게임의 보드게임 분위기와 해커톤 발표 톤에 맞는 배경음악을 VARCO AI로 제작했다.
  • 메뉴, 인게임, 승리 상황 등 흐름에 맞게 사운드 구성을 분리했다.
  • 사운드와 BGM은 게임 몰입감과 조작 피드백을 강화하는 용도로 사용했다.
  • 시작 화면에서 반복 재생될 수 있도록 가사가 없는 파티 게임 분위기의 BGM을 제작했다.
  • 효과음과 BGM의 볼륨 밸런스를 나눠 WebGL 환경에서도 과하게 들리지 않도록 적용했다.
