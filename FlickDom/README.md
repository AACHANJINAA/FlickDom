# FlickDom

## 작업 확인 원칙

- 모든 작업의 디버깅, 테스트, 수정 확인은 사용자가 직접 진행한다.
- 에이전트는 코드와 문서 수정까지 수행하고, 실행 결과 확인은 사용자가 맡는다.

## 개발 로그 작성 규칙

- 게임 구현 작업이 끝나면 반드시 `docs/DEVELOP_LOG.md`에 로그를 추가한다.
- `DEVELOP_LOG.md`에는 게임 구현과 직접 관련된 내용만 기록한다.
- 다음 항목은 기록하지 않는다.
- MCP 연결 또는 설정 작업
- AI 설정, 프로젝트, 에이전트 운영 규칙 관련 작업
- 게임 구현과 직접 관련이 없는 환경 또는 운영 설정
- 같은 날짜와 시간대의 작업은 한 묶음으로 정리하고, 세부 내용은 목록으로 기록한다.
- 시간은 큰 단위까지만 기록하고, 분 단위까지는 생략한다.
