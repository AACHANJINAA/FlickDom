# FlickDom

## Development Log Rule

- 게임 구현 작업을 완료하면 반드시 `docs/DEVELOP_LOG.md`에 로그를 남긴다.
- `DEVELOP_LOG.md`에는 게임 구현 관련 내용만 기록한다.
- 다음 항목은 기록하지 않는다.
  - MCP 연결/설정 작업
  - AI 설정, 프롬프트, 에이전트 운영 규칙 관련 작업
  - 게임 구현과 직접 관련 없는 환경/운영 설정
- 같은 날짜와 시간대의 작업은 한 글머리로 묶고, 세부 작업은 들여쓰기 목록으로 정리한다.
- 시간은 시 단위까지만 기록하고 분은 생략한다.
