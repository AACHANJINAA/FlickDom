# Develop Log

게임 구현 작업 완료 이력을 빠르게 파악하기 위한 로그 문서다.

## Logging Rule

- 하나의 TASK를 완료할 때마다 반드시 로그를 남긴다.
- `DEVELOP_LOG.md`에는 게임 구현 관련 작업만 기록한다.
- 아래 항목은 기록 대상에서 제외한다.
  - MCP 연결/설정
  - AI 동작 방식, 프롬프트, 에이전트 설정
  - 게임 구현과 직접 관련 없는 환경 설정
- 같은 날짜와 시간대의 작업은 한 글머리 안에 묶고, 세부 작업은 들여쓰기 목록으로 구분한다.
- 시간은 시 단위까지만 적고, 분은 적지 않는다.

  - 작업 1
  - 작업 2
