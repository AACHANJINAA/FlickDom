# Agent Instructions

이 저장소에서 작업하는 에이전트는 아래 규칙을 따른다.

## Develop log rule

- 게임 구현 관련 TASK를 완료하면 반드시 `docs/DEVELOP_LOG.md`를 업데이트한다.
- 로그는 작업 완료 직후 추가한다.
- 같은 날짜와 시간대의 작업은 하나의 글머리 아래에 묶고, 세부 항목은 들여쓰기 목록으로 정리한다.
- 로그 시간은 시 단위까지만 기록하고 분은 생략한다.

## Exclusions

다음 작업은 `docs/DEVELOP_LOG.md`에 기록하지 않는다.

- MCP 연결/설정
- AI 설정, 프롬프트, 에이전트 운영 규칙 변경
- 게임 구현과 직접 관련 없는 환경 설정

## Scope

기록 대상은 게임 구현 작업만 해당한다.

- 게임 로직
- 카드/점수/승리 규칙
- UI/HUD
- 씬 세팅
- 디버그 기능
- 게임 규칙 문서 업데이트
