# Contributing

## Required workflow

- 게임 구현 관련 TASK를 완료하면 반드시 `docs/DEVELOP_LOG.md`를 업데이트한다.
- 로그는 작업이 끝난 직후 추가한다.
- 같은 날짜와 시간대의 작업은 한 글머리로 묶고, 세부 작업은 들여쓰기 목록으로 정리한다.
- 시간은 시 단위까지만 기록하고 분은 생략한다.

## What must be logged

- 게임 시스템 구현
- UI 구현
- 점수/승리 규칙 변경
- 씬 세팅 변경
- 디버그 기능 추가
- 게임 플레이 규칙 문서화

## What must not be logged

- MCP 연결/설정 작업
- AI 프롬프트/에이전트 설정 작업
- 게임 구현과 직접 관련 없는 환경 설정

## Review checklist

- 작업 완료 내용이 `docs/DEVELOP_LOG.md`에 기록되었는가
- 게임 구현 로그만 남겼는가
- 같은 시간대 작업을 한 묶음으로 정리했는가
