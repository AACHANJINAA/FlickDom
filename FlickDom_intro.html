How To Play

게임 방법

목표

  • 각 플레이어는 3개의 플릭 디스크를 사용한다.
  • 디스크를 보드 위에 배치해 카드가 요구하는 패턴을 완성한다.
  • 카드는 Easy 1점, Normal 2점, Hard 3점을 준다.

조작

  • 라운드 시작 시 자신의 디스크 3개를 좌클릭해 순서를 정한다.
  • 마우스 또는 터치 드래그로 방향과 힘을 잡고 놓으면 발사된다.
  • 발사된 디스크는 다른 디스크나 벽에 닿아야 배치 후보가 된다.

종료 조건

  • 매치는 3개의 스테이지 카드 흐름으로 진행된다.
  • 점수 획득 직후 10점에 먼저 도달한 플레이어가 승리한다.
  • 승리 시 P1 WIN 또는 P2 WIN 화면이 표시된다.

Run Guide

실행 방법

Unity Editor 실행

  1. Unity Hub에서 프로젝트 폴더 FlickDom/FlickDom을 연다.
  2. Unity 버전은 6000.5.1f1 기준으로 실행한다.
  3. 시작 씬은 Assets/01_Scenes/Test_CJ/good_Scene.unity이다.
  4. Play 버튼으로 싱글모드 또는 멀티플레이 메뉴를 테스트한다.

WebGL 실행

  1. Unity 메뉴에서 FlickDom > Build > WebGL Release And Run을 사용한다.
  2. 또는 Build Profiles에서 Web 플랫폼을 선택하고 Build / Build And Run을 실행한다.
  3. 생성된 WebGL 폴더 전체를 Netlify 같은 정적 호스팅에 업로드한다.
  4. index.html은 직접 열지 말고 웹 서버 또는 호스팅 URL로 실행한다.

Development Summary

개발 요약

핵심 구현

  • 보드, 디스크, 카드, 점수, 승리 흐름을 갖춘 물리 기반 턴제 게임으로 구성했다.

  • WebGL 릴리스 빌드와 Netlify 업로드 흐름에 맞게 브라우저 실행을 지원한다.
